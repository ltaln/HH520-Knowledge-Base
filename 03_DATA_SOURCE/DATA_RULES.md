# Data Rules

## Golden Rules

1. Canonical production source = 10027s.
2. Match identity must be preserved.
3. Historical actual scores are labels, never predictors.
4. Do not invent unavailable fields.
5. Derived data must be labeled derived.
6. Preserve source/raw separation.
7. Stable prediction should be reproducible from structured pre-match input.
8. Do not use hidden post-match information.

## Result Leak Protection

If a historical record cannot be sanitized reliably, the record should be excluded or flagged rather than used.

## Field Authority

- page_probability: preferred when complete and valid
- 1X2 odds: probability fallback
- EV / Kelly: value context
- research_factors: risk/filter/research evidence
- actual HT/FT scores: labels only
- page_prediction.single / htft: raw page prediction-like fields
- score / goals generated by research models: derived only

## Match Linking

Historical result matching evolved to use:
1. DATE_MATCH_ID
2. DATE_TEAMS
3. UNIQUE_TEAMS fallback

Ambiguous matches must not be silently forced.
