# HH520 10027s Source Specification

## Canonical URL

```
https://www.hh520.com/tx/10027s.php?riqi_start=YYYY-MM-DD&riqi_end=YYYY-MM-DD&threshold=1&bankroll=5000
```

## Current Role

10027s is the **only official production source** for Stable V2.1.

Legacy 10023s support may still exist in code for compatibility or research, but it is not the canonical production source.

## Base Table Semantics

The base section contains identity and settlement-style fields including:
- date
- match id
- league
- kickoff
- 1X2 odds
- home/away team
- halftime score
- fulltime score
- EV
- Kelly
- recommendation/value fields

Important:
- halftime score = actual result label
- fulltime score = actual result label
- historical result labels must never enter pre-match inference

## Fusion Table Semantics

The fusion summary includes:
- 单选
- 融合真实概率
- 半全场
- 赔率判断
- 平赔率
- 融合平值
- 优势差
- 平局综合分
- 优势方
- 结构
- 一致
- 规律
- 评分
- 评级
- 风险
- 盘口
- 忽略

These fields feed research and, where explicitly approved, Decision Filter V2.

## Prediction Score / Total Goals

Inspection found no reliable raw 10027s predicted-score / predicted-total-goals field.

Therefore:
- do not label derived scores as HH520 raw
- derived score source must be explicit
- derived total goals source must be explicit

## Parser Safety

The parser must stop base-table scanning when the fusion table begins. This was fixed in the Stable V2.1 integration phase to prevent fusion rows being misread as base rows.
